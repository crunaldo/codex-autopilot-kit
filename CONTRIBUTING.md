# Contributing

Thanks for improving Codex Autopilot Kit.

## Development

Requirements:

- Node.js 20+
- Git

Run:

```bash
npm test
npm run verify
```

## Pull requests

Keep changes project-scoped and backwards-compatible. Any change to model defaults, permission semantics, backup behavior, or unattended execution must include tests and documentation.

Do not add automatic global Codex configuration or silent installation of third-party bridges.
