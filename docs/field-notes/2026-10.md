# Field notes — October 2026

These are anecdotal controlled observations, not official benchmarks or guarantees.

## Experiment A — unconstrained high-end delegation

- PASS, ~10m44s
- Goal telemetry ~1.36M tokens
- delegated models included high-end Sol/Astra variants
- observed 5-hour meter roughly 100% -> 40%

Takeaway: unconstrained high-end delegation can consume plan capacity quickly.

## Experiment B — controlled Luna Medium/High

- PASS, ~12m17s
- Goal telemetry ~1.97M tokens
- worker Luna Medium, reviewer Luna High
- observed 5-hour meter 66% -> 66%

Takeaway: Goal token telemetry did not correlate directly with the visible plan meter.

## Experiment C — Web supervisor + Luna High worker/reviewer

- PASS, ~8m28s
- Goal telemetry ~1.52M tokens
- explorer unused
- worker GPT-6 Luna High, 2 passes
- reviewer GPT-6 Luna High, 1 pass
- diff 248 insertions / 35 deletions across four files
- tests PASS
- observed 5-hour meter 66% -> 65%
- observed weekly meter 83% -> 82%

Operational recoveries included a rejected combined inspection command, a subagent spawn argument adjustment, waiting for concurrency=1 before reviewer, and using `git diff-files` after a transient worktree issue.

## Practical conclusion

Use quota meters and real outcomes as primary operational signals. Treat Goal token telemetry as informational, especially with Web supervisor routing, cache/replay accounting, or subagent contexts.
